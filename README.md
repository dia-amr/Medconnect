# Medconnect

## Description

Plateforme Web de gestion des disponibilités des médecins et des rendez-vous médicaux.

## Fonctionnalités principales

- Gestion des médecins
- Gestion des comptes médecins et utilisateurs
- Recherche de médecins
- ## Installation

```bash
git clone https://github.com/username/EduConnect.git
```

Ouvrez index.html dans un navigateur.
